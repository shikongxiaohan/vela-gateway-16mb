# 刷写说明

分两种情况：**第一次刷必须用数据线**，**以后升级用手机网页就行**。

固件文件在 [`firmware/`](../firmware/) 目录，历史版本在 [Releases](../../releases)。

| 文件 | 用途 | 大小 |
|---|---|---|
| `*-factory.bin` | 整包（bootloader + 分区表 + otadata + app），USB 整片刷写 | ~1.71 MB |
| `*-ota.bin` | 只含 app，网页 OTA 升级 | ~1.58 MB |

---

## 一、第一次刷（USB 数据线）

手机做不到这一步。刷整片 Flash 要走 ESP32 的 ROM 串口下载模式（拉低 GPIO0 再复位），必须有物理串口连接；iOS 没有 USB 串口驱动，Android 的 WebSerial 也只在桌面版 Chrome 可用。

### Flash Download Tool（Windows，推荐）

下载：[乐鑫官方工具页](https://www.espressif.com.cn/zh-hans/support/download/other-tools)，文件名形如 `flash_download_tool_x.x.x.zip`，解压运行 `flash_download_tool.exe`。

1. **ChipType** 选 `ESP32` → **WorkMode** 选 `Develop` → **LoadMode** 选 `UART` → 点 `OK`
2. 主界面填：

| 位置 | 填什么 |
|---|---|
| 文件 | `*-factory.bin` |
| 起始地址 | **`0x0`** |
| SPIDownload 勾选 | ✔ |
| SPI SPEED | `80MHz` |
| SPI MODE | `DIO` |
| FLASH SIZE | **`16MB`** ← 最容易错 |
| BAUD | `921600`（不稳就降 `460800` / `115200`） |

3. 勾选 **`DoNotChgBin`**
4. 点 `ERASE` 等擦完 → 点 `START` 等 `FINISH`
5. 按一下板子的 RST 键

**只需填一行 `0x0`**，因为 factory 已经把四段合并好了。

> ⚠️ 换分区表必须整片擦除。旧 4MB 版的 otadata 会让 bootloader 找错分区，不擦会反复重启。

### 命令行

```bash
./flash_16mb.sh /dev/ttyUSB0     # Linux / macOS
flash_16mb.bat COM3               # Windows
```

### 分开刷（一般不需要）

| 文件 | 地址 |
|---|---|
| `bootloader.bin` | `0x1000` |
| `partitions.bin` | `0x8000` |
| `ota_data_initial.bin` | `0xE000` |
| `*-ota.bin` | `0x20000` |

> ⚠️ 应用地址是 `0x20000`，不是 4MB 版的 `0x10000`。填错会打 `invalid header: 0xffffffff` 然后不断重启。

### 进不了下载模式

按住 BOOT 不放 → 点 RST → 松开 RST → 再松开 BOOT。

## 二、之后升级（手机网页 OTA）

1. 手机连设备热点（默认 `Vela-Setup`，密码 `12345678`）
2. 浏览器打开 `http://192.168.4.1/`
3. **系统**页 → **进入空中升级**，设备重启后自动跳到升级页
4. 第一张卡是**刷写前自检**，显示芯片型号、Flash 容量、当前/目标分区。确认显示 `16.00 MB ✅` 再继续
5. 点 **选择固件并升级**，选 `*-ota.bin`
6. 页面先本地读文件头确认是 app 镜像（防误传整包），再弹确认
7. 进度条实时显示百分比，传完自动重启，约 15 秒后热点重新出现

整个过程 30–60 秒。

> 传错文件会被拦下，提示"这不是 app 镜像（缺少 app 描述符）"，**不会写坏设备**——校验发生在写入之前。

### 三道校验闸

1. **前端**：`File.slice(0,36)` 读文件头，魔数不对直接拦，连上传都不发
2. **首包**：ESP32 收到第一个 1KB 就校验，不对立即置错并丢弃后续
3. **不调用 `Update.end()`**：错误状态绝不提交分区切换，旧固件原封不动

---

## 三、刷坏了怎么救

固件是 **A/B 双分区 + 回滚保护**：新固件连续启动失败，bootloader 自动切回上一个可用分区。

两个分区都坏了（比如断电断在写 otadata 的瞬间），只能 USB 救：整片擦除后重刷 factory 镜像。

---

## 四、常见问题

**手机上点"选择固件"没反应？**
部分国产 ROM 的浏览器拦了 `input[type=file]` 的 `click()`。用页面下方原生文件选择框，走同一套逻辑。

**上传到一半卡住？**
多半是 iOS 把页面冻结了（切 App、锁屏、下拉通知栏）。重试即可，中断不会损坏设备——分区切换只在 `Update.end()` 那一刻发生。

**显示"网络中断，上传失败"？**
Wi-Fi 断了或热点被抢。设备没被改动，重试。

**刷完重启进不去管理台？**
等 20 秒。如果热点在但页面打不开，断电 → 按住 BOOT → 上电 → 松手，进配网模式。
