# 刷写说明

第一次刷得用数据线，之后升级用手机网页就行。

固件在 [`firmware/`](../firmware/)，旧版本在 [Releases](../../releases)。

| 文件 | 用途 | 大小 |
|---|---|---|
| `*-factory.bin` | 整包（bootloader + 分区表 + otadata + app），USB 整片刷 | 约 1.74 MB |
| `*-ota.bin` | 只有 app，网页 OTA 用 | 约 1.61 MB |

## 一、第一次刷（数据线）

这一步手机做不了。整片刷 Flash 要进 ESP32 的 ROM 串口下载模式（拉低 GPIO0 再复位），必须物理串口。iOS 没有 USB 串口驱动，Android 的 WebSerial 也只有桌面版 Chrome 支持。

### Flash Download Tool（Windows）

先从[乐鑫工具页](https://www.espressif.com.cn/zh-hans/support/download/other-tools)下 `flash_download_tool_x.x.x.zip`，解压运行 `flash_download_tool.exe`。

启动时选 `ESP32` / `Develop` / `UART`，点 OK。主界面填这些：

| 位置 | 填什么 |
|---|---|
| 文件 | `*-factory.bin` |
| 起始地址 | `0x0` |
| SPIDownload 勾选 | ✔ |
| SPI SPEED | `80MHz` |
| SPI MODE | `DIO` |
| FLASH SIZE | `16MB`（最容易填错的一项） |
| BAUD | `921600`，不稳就降到 `460800` 或 `115200` |

勾上 `DoNotChgBin`，点 `ERASE` 等擦完，再点 `START` 等 `FINISH`，最后按一下板子的 RST。

只需要填一行 `0x0`，factory 已经把四段合并好了。

> 换过分区表就必须整片擦除。旧 4MB 版留下的 otadata 会让 bootloader 找错分区，不擦会一直重启。

### 命令行

```bash
./flash_16mb.sh /dev/ttyUSB0     # Linux / macOS
flash_16mb.bat COM3               # Windows
```

### 分开刷

一般用不到，除非只想单独更新某一段。

| 文件 | 地址 |
|---|---|
| `bootloader.bin` | `0x1000` |
| `partitions.bin` | `0x8000` |
| `ota_data_initial.bin` | `0xE000` |
| `*-ota.bin` | `0x20000` |

应用地址是 `0x20000`，不是 4MB 版的 `0x10000`。填错的话启动会打 `invalid header: 0xffffffff`，然后一直重启。

### 进不了下载模式

按住 BOOT 不放，点一下 RST，松开 RST，再松开 BOOT。

## 二、之后升级（手机网页）

1. 手机连设备热点，默认 `Vela-Setup` / `12345678`
2. 浏览器打开 `http://192.168.4.1/`
3. 进系统页，选 `-ota.bin`，传进设备，列表里点一行选中，再点「升级到选中版本」
4. 设备自己校验镜像、写进备用分区，然后重启切过去

整个过程 30 到 60 秒。传错文件会在写入之前被拦下来，提示「这不是 app 镜像」，设备不会被写坏。

校验在三处做，任一处不过都不会提交分区切换：

- 上传时读文件头，魔数不对直接拦，连传都不传
- ESP32 收到第一个 1KB 就验，不对立刻置错并丢掉后续数据
- 出错就不调 `Update.end()`，旧固件原封不动

## 三、刷坏了怎么救

固件跑在 A/B 双分区上，带回滚保护。新固件连续启动失败，bootloader 会自己切回上一个能用的分区。

两个分区都坏了（比如断电正好断在写 otadata 的时候），只能插数据线救：整片擦除，重刷 factory。

## 四、常见问题

**手机上点「选择固件」没反应。**
部分国产 ROM 的浏览器拦了 `input[type=file]` 的 `click()`。用页面下方的原生文件选择框，逻辑是一样的。

**传到一半卡住了。**
多半是 iOS 把页面冻结了，切 App、锁屏、下拉通知栏都会。重试就行，中断不会坏设备，分区切换只在 `Update.end()` 那一刻发生。

**提示「网络中断，上传失败」。**
Wi-Fi 断了或者热点被抢。设备没被改动，重试。

**刷完重启进不去管理台。**
先等二十秒。如果热点在但页面打不开，断电，按住 BOOT 上电，松手，会进配网模式。
