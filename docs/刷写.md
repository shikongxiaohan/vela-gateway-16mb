# 刷写说明

首次烧录需使用数据线，后续升级可通过网页完成。

固件位于 [`firmware/`](../firmware/)，历史版本见 [Releases](../../releases)。

| 文件 | 用途 | 大小 |
|---|---|---|
| `*-factory.bin` | 完整固件包（bootloader + 分区表 + otadata + 应用），USB 整片写入 | 约 1.74 MB |
| `*-ota.bin` | 应用镜像，用于网页 OTA | 约 1.61 MB |

## 一、首次烧录（数据线）

该步骤无法在移动设备上完成。整片写入 Flash 需使 ESP32 进入 ROM 串口下载模式（拉低 GPIO0 后复位），必须依赖物理串口。iOS 不提供 USB 串口驱动，Android 的 WebSerial 仅桌面版 Chrome 支持。

### Flash Download Tool（Windows）

从[乐鑫工具页](https://www.espressif.com.cn/zh-hans/support/download/other-tools)下载 `flash_download_tool_x.x.x.zip`，解压后运行 `flash_download_tool.exe`。

启动界面选择 `ESP32` / `Develop` / `UART`，点击 OK。主界面参数如下：

| 参数 | 取值 |
|---|---|
| 文件 | `*-factory.bin` |
| 起始地址 | `0x0` |
| SPIDownload 勾选 | 勾上 |
| SPI SPEED | `80MHz` |
| SPI MODE | `DIO` |
| FLASH SIZE | `16MB`，需与硬件实际容量一致 |
| BAUD | `921600`，链路不稳时降至 `460800` 或 `115200` |

勾选 `DoNotChgBin`，点击 `ERASE` 完成擦除，再点击 `START` 执行写入，待状态显示 `FINISH` 后按一次开发板 RST 键。

仅需填写 `0x0` 一行，factory 镜像已合并全部分区。

> 更换分区表后必须执行整片擦除。旧 4 MB 布局残留的 otadata 会导致 bootloader 定位到错误分区，未擦除将出现持续重启。

### 命令行

```bash
./flash_16mb.sh /dev/ttyUSB0     # Linux / macOS
flash_16mb.bat COM3               # Windows
```

### 分段烧录

仅在需要单独更新某一分区时使用。

| 文件 | 地址 |
|---|---|
| `bootloader.bin` | `0x1000` |
| `partitions.bin` | `0x8000` |
| `ota_data_initial.bin` | `0xE000` |
| `*-ota.bin` | `0x20000` |

应用分区地址为 `0x20000`，非 4 MB 布局下的 `0x10000`。地址填写错误将导致启动时报 `invalid header: 0xffffffff` 并持续重启。

### 进入下载模式

保持 BOOT 键按下，短按 RST 键，随后先释放 RST，再释放 BOOT。

## 二、网页升级

1. 手机与设备处于同一网络（家庭 Wi-Fi 或设备热点）
2. 浏览器打开管理台，进入设置页
3. 点击「固件升级」卡片中的「进入空中升级」，确认后设备重启
4. 设备重启后只开启热点 `VELA-...`，浏览器打开该热点下的 `192.168.4.1`，在升级页选择 `-ota.bin` 写入
5. 写入完成点击「返回网关」，设备再次重启进入网关模式

空中升级模式下蓝牙桥接不运行，射频与内存全部让给网页写入。配置、手表密钥、表盘与快应用均保留。

文件类型不符将在传输开始前被拦截，提示「不是应用镜像」，设备状态不变。校验分三处，任一处未通过均不提交分区切换：

- 选择文件后读取前 36 字节，首字节不是 `0xE9` 或偏移 `0x20` 处不是 `0xABCD5432` 即拦截
- 设备接收首个数据块时再校验一次，失败立即置错并丢弃后续数据
- 校验失败不调用 `Update.end()`，原有固件保持不变

## 三、故障恢复

固件运行于 A/B 双分区，具备回滚保护。新固件连续启动失败时，bootloader 将自动切换至上一可用分区。

若两个分区均不可用（例如写入 otadata 期间断电），只能通过数据线恢复：整片擦除后重新烧录 factory 镜像。

## 四、常见问题

**点击「选择固件」无响应。**
部分定制 Android ROM 的浏览器限制了 `input[type=file]` 的 `click()` 调用。可使用页面上的原生文件选择控件，功能一致。

**传输中断。**
通常由 iOS 页面冻结引起，切换应用、锁屏、下拉通知栏均会触发。重新操作即可，中断不会损坏设备，分区切换仅在 `Update.end()` 调用时发生。设备界面会提示「上传因网络中断失败，设备状态未改变」。

**上传进度停在某个百分比。**
说明链路断在写入过程中。重新上传即可；若反复停在同一位置，先确认手机与设备之间没有省电模式切断后台连接。

**写入成功但重启后版本没变。**
说明新固件启动失败并被 bootloader 回滚。回到管理台，系统页「上次升级未生效」会显示目标版本与实际运行版本。

**设备一直停在升级页，回不到网关。**
升级页底部有「返回网关」按钮。若手机已断开，设备在连续 3 分钟没有收到任何请求后会自动切回网关并重启；急用时长按 BOOT 也可强制进入配网模式。

**提示「上一条还在投递中」。**
蓝牙推送同一时刻只能投递一条。等前一条返回结果（最多 8 秒）再发。

**烧录后重启无法访问管理台。**
等待约 20 秒。若热点存在但页面无法打开，断开电源，按住 BOOT 上电后释放，设备将进入配网模式。
